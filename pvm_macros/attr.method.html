#[method]
Expand description

Marks a function as a contract method with a Solidity-style signature.

§Signature Format

"functionName(type1,type2) returns (returnType)"

The signature is used to:

  1. Compute the 4-byte selector (keccak256 hash of canonical signature)
  2. Generate ABI decoding for input parameters
  3. Generate ABI encoding for return values

§Return Types

Methods support two return patterns:

ⓘ
// Fallible - can revert with error
#[pvm::method("transfer(address,uint256)")]
pub fn transfer(to: Address, amount: U256) -> Result<(), Error> { ... }

// Infallible - always succeeds
#[pvm::method("balanceOf(address) returns (uint256)")]
pub fn balance_of(account: Address) -> U256 { ... }
