pvm_macros

Attribute Macro contract 

Source 
#[contract]
Expand description

Marks a module as a PVM smart contract, generating the dispatch logic and entry points.

§Attributes

  • no_alloc - Disables the global allocator (uses fixed-size stack buffers)
  • buffer = N - Sets the calldata buffer size for no_alloc mode (default: 256)

§Example

ⓘ
use pvm::{Address, Error, U256};

#[pvm::contract]
mod my_token {
    use super::*;

    #[pvm::constructor]
    pub fn new() -> Result<(), Error> {
        Ok(())
    }

    // Fallible method - returns Result<T, Error>
    #[pvm::method("transfer(address,uint256)")]
    pub fn transfer(to: Address, amount: U256) -> Result<(), Error> {
        if get_balance(&pvm::caller()) < amount {
            return Err(Error::InsufficientBalance);
        }
        // ... transfer logic
        Ok(())
    }

    // Infallible method - returns T directly (no Result wrapper)
    #[pvm::method("totalSupply() returns (uint256)")]
    pub fn total_supply() -> U256 {
        get_total_supply()
    }

    // Infallible with no return value
    #[pvm::method("mint(address,uint256)")]
    pub fn mint(to: Address, amount: U256) {
        set_balance(&to, get_balance(&to) + amount);
    }

    #[pvm::fallback]
    pub fn fallback() -> Result<(), Error> {
        Err(Error::UnknownSelector)
    }
}

§Generated Code

The macro generates:

  • deploy() - Constructor entry point
  • call() - Dispatcher that routes calls by selector
  • Selector computation from Solidity signatures
  • ABI encoding/decoding for parameters and return values

§Return Type Flexibility

Methods can return either:

Result<T, Error> - For fallible operations:

ⓘ
#[pvm::method("transfer(address,uint256)")]
pub fn transfer(to: Address, amount: U256) -> Result<(), Error> {
    // Can return Err(Error::...) to revert
}

T (plain value) - For infallible operations:

ⓘ
#[pvm::method("totalSupply() returns (uint256)")]
pub fn total_supply() -> U256 {
    get_total_supply()  // Always succeeds
}

The macro detects the return type and generates appropriate dispatch code:

  • Result<T, Error> → method().map(encode).map_err(|e| e.as_ref())
  • T → Ok(encode(method()))

§Error Handling

Use pvm::Error for revertable errors:

ⓘ
pub enum Error {
    InsufficientBalance,
    UnknownSelector,
    InvalidCalldata,
    CalldataTooLarge,
    Custom(&'static [u8]),  // For custom error messages
}

Error implements AsRef<[u8]>, so errors are automatically converted to byte slices for the revert data.

§No-Alloc Mode

For minimal binary size, use no_alloc:

ⓘ
#[pvm::contract(no_alloc, buffer = 512)]
mod my_contract {
    // Uses stack-allocated buffers instead of Vec
}
